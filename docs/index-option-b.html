Everything your agent
needs to see.

01

Live Screenshots Streaming

Real-time screenshots from the simulator at up to 15 FPS. Your agent sees exactly what the user sees — pixel-accurate.

02

Network Inspector Intercepted

Every request, response, header, and body captured at the URLSession level. Full detail view per request.

03

View Hierarchy

The full SwiftUI and UIKit view tree at any depth. Find invisible overlays, misaligned frames, and broken hit-testing.

04

Logs

os_log, print, stderr — all captured and filterable by level, keyword, and source.

05

UI Interaction New

Tap, swipe, type, long-press — control the app from your editor. Target views by accessibility identifier, label, or path.

06

22 MCP Tools

Memory, keychain, UserDefaults, file browser, object inspector, class introspection, diagnostics, and more. All callable by your agent.

07

Debug-only. Zero footprint.

Wrap in #if DEBUG and Apus vanishes from release builds. Zero dependencies. Localhost-only.

Three steps.

That’s it.

1
Add the Swift package
// Package.swift dependencies: [ .package(url: "https://github.com/anthropics/apus.git", from: "0.3.0") ]
2
Start Apus
import SwiftUI #if DEBUG import Apus #endif @main struct MyApp: App { init() { #if DEBUG Apus.shared.start(interceptNetwork: true) #endif } }
3
Point your agent
{ "mcpServers": { "apus": { "type": "http", "url": "http://localhost:9847/mcp" } } }
