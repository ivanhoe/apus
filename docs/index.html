Setup

Up and running
in 3 steps.

1
Add the Swift package
// Package.swift dependencies: [ .package(url: "https://github.com/anthropics/apus.git", from: "0.3.0") ]
2
Start Apus in your app entry point
import SwiftUI #if DEBUG import Apus #endif @main struct MyApp: App { init() { #if DEBUG Apus.shared.start(interceptNetwork: true) #endif } }
3
Add .mcp.json to your project root
{ "mcpServers": { "apus": { "type": "http", "url": "http://localhost:9847/mcp" } } }
